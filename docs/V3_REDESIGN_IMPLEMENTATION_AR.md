# تطبيق التصميم المطور V3

تم تطبيق البرومبت الجديد كنظام تصميم موحد على كل الواجهات بدون CDN وبدون تغيير Routes أو Workflows.

## الملفات

- `assets/amin-v3.css`
- تم ربطه بكل صفحات HTML بعد `brand-redesign.css` حتى يلغي التنسيقات القديمة بصرياً.
- تم تحديث `sw.js` لإدخال الملف في PWA cache.

## الألوان المعتمدة

```txt
--c-primary: #6B2D6B
--c-primary-mid: #8B4A8B
--c-primary-light: #A855A8
--c-accent: #D4956A
--c-accent-light: #E8C5A0
--c-bg: #F5EDE4
--c-surface: #FDF6F0
--c-surface-2: #F2D9C0
--c-text: #3D2040
```

## ما تم

- إعادة بناء الطبقة البصرية للصفحات.
- توحيد ألوان كل الواجهات.
- Override للتنسيقات القديمة دون كسر الكود.
- تحسين البطاقات، الأزرار، القوائم، الجداول، التبويبات، الحقول.
- دعم Dark Mode بنفس الهوية.
- إزالة التكرارات البصرية عبر اعتماد طبقة موحدة.

## ملاحظات

- لم يتم استخدام Google Fonts أو CDN.
- لم يتم حذف أي Route أو API.
- لا يوجد SQL مطلوب.
