# وحدة الجانب النفسي / الإرشاد النفسي

تم تنفيذ صفحة سريعة ومتكاملة للمرشد النفسي المدرسي، مبنية على فكرة السرية، سرعة الوصول، وتوثيق الجلسات بصيغة SOAP.

## الملفات المضافة

- `counselor.html`
- `assets/counselor.js`
- `assets/counselor.css`
- `sql/archive/98_counseling_psychological_workspace.sql`

## الملفات المعدلة

- `assets/platform-modules.js` لإضافة وحدة الإرشاد النفسي إلى البوابة.
- `staff.html` لإضافة رابط سريع للجانب النفسي.
- `assets/i18n.js` لإضافة ترجمات أساسية.
- `sw.js` لإضافة الصفحة إلى PWA cache.

## الميزات المنفذة

1. **قائمة الحالات النشطة**
   - فلترة حسب: الكل، عاجل، مرتفع، متابعة، مستقر، اليوم.
   - بطاقة مختصرة لكل طالب مع مستوى المتابعة والتقدم.

2. **ملف الطالب النفسي**
   - نظرة عامة.
   - جلسات SOAP.
   - التقييمات.
   - الأهداف.
   - الأسرة والتواصل.
   - الوثائق السرية.

3. **جلسات SOAP**
   - S: ما قاله الطالب.
   - O: ما لاحظه المرشد.
   - A: تقييم المرشد.
   - P: الخطة القادمة.
   - مستوى المتابعة.
   - المزاج قبل/بعد.
   - موعد المتابعة القادم.

4. **الأهداف الإرشادية**
   - أهداف SMART.
   - مجال الهدف.
   - مؤشر قياس.
   - نسبة تقدم.

5. **الإحالات والتنبيهات**
   - إحالات جديدة.
   - قبول/تأجيل/رفض الإحالة.
   - إنشاء حالة تلقائياً عند قبول الإحالة.

6. **لوحة يومية للمرشد**
   - جلسات اليوم.
   - المهام المعلقة.
   - إحالات جديدة.
   - نبض المدرسة.

7. **خصوصية وقفل الشاشة**
   - زر قفل الشاشة.
   - اختصار Ctrl+L.
   - قفل تلقائي بعد 3 دقائق خمول.
   - PIN محلي على الجهاز.

8. **سجل وصول**
   - يسجل فتح واجهة الإرشاد وعمليات الملفات الحساسة في `counseling_access_logs`.

## ملاحظة خصوصية

هذه الوحدة تفصل بيانات الإرشاد النفسي في جداول خاصة، ولا تعرض تفاصيل الجلسات للمعلمين أو أولياء الأمور. يمكن لاحقاً إضافة تشفير إضافي للملاحظات الحساسة إن رغبت الإدارة.

## تحديث V2 السريع

تمت إضافة تحسينات النسخة الثانية:

- إخفاء مستوى الخطورة من قائمة الحالات؛ يظهر الاتجاه فقط داخل القائمة، والتفاصيل داخل ملف الطالب.
- استبدال الرادار بمؤشر نصي صادق: اتجاه + مصدر البيانات.
- وضع جلسة نشطة Minimal Mode: مؤقت + ملاحظات حية + بروتوكول أزمة.
- بعد إنهاء الجلسة تنتقل الملاحظات إلى نموذج SOAP للتوثيق.
- إضافة بروتوكول الجلسة ثقافياً: مفتوح الباب / ولي أمر قريب / جماعية / عن بُعد بوجود ولي أمر.
- تسمية خارجية محايدة: "برنامج تطوير المهارات والمتابعة التربوية" بدلاً من مصطلحات قد تسبب وصمة.
- استمرار قفل الخصوصية Ctrl+L والقفل التلقائي.


## تحديث Offline Autosave

تمت إضافة حفظ تلقائي محلي لجلسات المرشد:

- أثناء الجلسة النشطة يتم حفظ الملاحظات محلياً تلقائياً.
- يظهر مؤشر اتصال: متصل / غير متصل.
- زر `المسودات` يعرض كل المسودات المحلية.
- يمكن استعادة مسودة جلسة حية.
- إذا فشل حفظ SOAP بسبب انقطاع الاتصال، تحفظ الجلسة كمسودة جاهزة للمزامنة.
- عند عودة الاتصال يمكن ضغط `مزامنة` لحفظها في قاعدة البيانات.

هذا يقلل خطر فقدان ملاحظات الجلسة عند انقطاع الإنترنت أو إغلاق المتصفح بالخطأ.


## تحديث بروتوكول تسليم الحالات

تمت إضافة بروتوكول تسليم موثق بين مرشد وآخر:

- المرشد الحالي ينشئ تسليم حالة.
- يحدد المرشد المستلم.
- يكتب: الوضع الراهن، أبرز ما يجب معرفته، ما لم يكتمل، التوصية.
- المرشد المستلم يضغط `استلام الحالة`.
- تنتقل مسؤولية الحالة تلقائياً له في قاعدة البيانات.
- يتم تسجيل العملية في سجل الوصول.

SQL المطلوب:

```txt
sql/archive/107_counseling_handover_protocol.sql
```

الفحص:

```sql
select public.counseling_handover_health_check();
```


```sql

```

```txt

```
