# نظام الإنجازات والشارات التحفيزية

تمت إضافة قسم مستقل للإنجازات والشارات للطلاب والمعلمين.

## الملفات المضافة

- `achievements.html`
- `assets/achievements.js`
- `assets/achievements.css`
- `sql/97_achievements_badges_system.sql`
- تحديث `assets/platform-modules.js` لإظهار الوحدة في البوابة الموحدة
- تحديث `student.html` و `teacher.html` لإضافة رابط الإنجازات
- تحديث `smart-calendar.js` لربط إنجازات الأجندة بالشارات

## ما يقدمه القسم

1. **شارات تحفيزية للطلاب**
   - نجم الحضور
   - بطل الواجبات
   - تميز الاختبارات
   - بطل التحسن
   - جوهرة الانضباط
   - قارئ المكتبة
   - بطل الأنشطة
   - شارة اللطف
   - منجز اليوم
   - باحث المختبر

2. **شارات تحفيزية للمعلمين**
   - المعلم الملهم
   - مايسترو الحضور
   - مرشد الواجبات
   - صانع الاختبارات
   - المعلم الرقمي
   - داعم الطلاب
   - باني الصف
   - معلّم الابتكار

3. **لوحة صدارة**
   - ترتيب الطلاب حسب النقاط
   - ترتيب المعلمين حسب النقاط

4. **منح يدوي**
   - الإدارة تمنح للطلاب والمعلمين.
   - المعلم يستطيع منح شارات للطلاب ضمن نطاق طلابه.

5. **منح تلقائي**
   - من تسليم الواجبات.
   - من درجات الاختبارات.
   - من سجلات الحضور.
   - من إنجازات الأجندة.
   - من إنشاء المعلم للواجبات والاختبارات.

## طريقة التفعيل

شغّل الملف التالي من Supabase SQL Editor:

```txt
sql/97_achievements_badges_system.sql
```

ثم افتح الصفحة:

```txt
achievements.html
```

أو من البوابة الموحدة باسم:

```txt
الإنجازات والشارات
```

## فحص الصحة

بعد تشغيل SQL يمكن تنفيذ:

```sql
select public.achievements_health_check();
```

النتيجة المتوقعة:

```json
{
  "ok": true,
  "tables": {
    "achievement_badges": true,
    "achievement_awards": true
  }
}
```
