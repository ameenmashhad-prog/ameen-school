# مخطط المنهج الذكي القابل للتعديل

تم تنفيذ وحدة تخطيط المنهج مع أولوية كاملة لقابلية تعديل المعلم.

## الملفات

- `curriculum-planner.html`
- `assets/curriculum-planner.js`
- `assets/curriculum-planner.css`
- `sql/archive/110_curriculum_planner_editable.sql`

## الميزات

- استيراد المنهج من نص الفهرس أو ملف نصي.
- حفظ اسم ملف PDF/صورة كمرجع، مع إمكانية لصق النص المستخرج.
- توليد خطة تلقائية حسب عدد الدروس في الأسبوع.
- تقسيم سنوي/شهري/أسبوعي تلقائي.
- تعديل كامل لكل درس.
- نقل الدروس بين الأسابيع بالسحب والإفلات.
- إضافة درس مخصص.
- إعادة توزيع الدروس المتبقية فقط دون لمس المكتمل.
- نسخ احتياطية قبل إعادة التوزيع.
- سجل تعديلات audit.
- مؤشرات تقدم ديناميكية.

## SQL المطلوب

```txt
sql/archive/110_curriculum_planner_editable.sql
```

ثم افحص:

```sql
select public.curriculum_planner_health_check();
```

## تحديث ربط العطل الرسمية وحصص الأسبوع

تمت إضافة ملف:

```txt
sql/archive/112_curriculum_holidays_weekly_schedule_fix.sql
```

وظيفته:

- ضبط الدولة الحالية إلى إيران `IR`.
- ضبط نهاية الأسبوع إلى الجمعة حسب إعدادات إيران الافتراضية.
- إضافة قواعد عطلات إيران الرسمية الثابتة بالتقويم الشمسي.
- توليد العطل داخل السنوات الدراسية الموجودة.
- استبعاد العطل ونهاية الأسبوع أثناء توزيع دروس المنهج.
- استنتاج عدد حصص المادة في الأسبوع من `weekly_schedule` حسب:
  - المعلم
  - الصف
  - الشعبة إن وجدت
  - المادة
  - الفصل الدراسي إن وجد
- إعادة توزيع الدروس المتبقية دون لمس الدروس المكتملة.

الفحص:

```sql
select public.curriculum_holidays_weekly_schedule_health_check();
```

ملاحظة: عند إنشاء خطة جديدة، اتركي عدد الحصص في الأسبوع = `0` ليتم اكتشاف العدد تلقائياً من الجدول المدرسي.

## ربط الخطة السنوية بالواجبات

أضيف الملف:

```txt
sql/archive/116_curriculum_homework_link_badge_levels.sql
```

المزايا:

- في نموذج الواجب داخل لوحة المعلم تظهر قائمة منسدلة باسم: `درس من الخطة السنوية`.
- يمكن اختيار درس من الخطة أو تركه فارغاً وكتابة موضوع حر مثل مراجعة أو نشاط.
- عند نشر واجب مرتبط بدرس من الخطة، يتم تعليم الدرس تلقائياً كمُعطى ومكتمل في الخطة.
- يتم تسجيل العملية في سجل تعديلات المنهج.

الفحص:

```sql
select public.curriculum_homework_badge_levels_health_check();
```

## مستويات شارات الإنجاز

تمت إضافة مستويات تراكمية للشارات:

- برونزية
- فضية
- ذهبية
- ماسية

مثال للمعلم:

- 30 تحضير = برونزية
- 60 تحضير = فضية
- 90 تحضير = ذهبية
- 120 تحضير = ماسية

وتطبق نفس الفكرة على تصحيح الواجبات، تنزيل الدرجات، متابعة الحضور، واختبارات إلكترونية حسب نوع الشارة.
