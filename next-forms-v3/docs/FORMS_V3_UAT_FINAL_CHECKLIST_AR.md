# قائمة UAT النهائية — next-forms-v3

## الحالة الحالية المختصرة
### Backend
تم التحقق أن SQL التالية تعمل على البيئة الحية:
- `144_forms_v3_engine_foundation.sql`
- `145_forms_v3_submissions_review.sql`
- `146_forms_v3_leave_request_submit.sql`
- `147_forms_v3_teacher_evaluation_submit.sql`
- `148_forms_v3_financial_permission_submit.sql`
- `149_forms_v3_student_registration_packet_submit.sql`
- `150_forms_v3_submission_name_fallbacks.sql`

### RPC
تم التحقق من:
- health check
- save draft
- list versions
- upload ticket flow
- submit للنماذج الأساسية
- list / get / update status في لوحة الطلبات

### Route Smoke محلي
تم التحقق محليًا أن الصفحات التالية تستجيب بحالة `200`:
- `/ar`
- `/ar/forms/student-registration`
- `/ar/forms/student-registration-packet`
- `/ar/forms/leave-request`
- `/ar/forms/teacher-evaluation`
- `/ar/forms/financial-permission`
- `/ar/forms/submissions`

---

## هدف UAT
التأكد أن المستخدم الإداري/المدرسي يستطيع:
- فتح النماذج
- تعبئة الحقول الأساسية
- تجهيز تذكرة رفع المرفق عند الحاجة
- إرسال الطلب بنجاح
- رؤية صفحة النجاح
- رؤية الطلب في لوحة الطلبات المرسلة
- تغيير الحالة وقراءة التفاصيل
- طباعة النسخة عند الحاجة

---

# 1) فحص عام قبل البدء

## 1.1 فتح الواجهة
- [ ] الصفحة الرئيسية تفتح
- [ ] تظهر روابط النماذج الستة بوضوح
- [ ] التبديل اللغوي يعمل
- [ ] الاتجاه RTL صحيح للعربية والفارسية
- [ ] لا يوجد نص hardcoded مكسور أو placeholder غريب

## 1.2 فحص الخطوط والمظهر
- [ ] العربية تظهر بخط عربي مناسب
- [ ] الفارسية تظهر بخط فارسي مناسب
- [ ] الإنكليزية تظهر بخط لاتيني مناسب
- [ ] الأزرار واضحة
- [ ] عناصر الطباعة لا تظهر في وضع الشاشة إلا عند الحاجة

## 1.3 فحص الحفظ
- [ ] حفظ المسودة اليدوي يعمل
- [ ] الحفظ التلقائي لا يسبب أخطاء ظاهرة
- [ ] عداد النسخ أو سجل النسخ يظهر بشكل منطقي

- [ ] كل الصفحات الرئيسية تفتح
- [ ] كل النماذج الأساسية ترسل بنجاح
- [ ] لوحة الطلبات تعرض البيانات بشكل صحيح
- [ ] الطباعة تعمل في فورم التسجيل المطبوع
- [ ] upload ticket flow يعمل
- [ ] لا توجد أخطاء blocking في العربية
- [ ] لا توجد أخطاء حرجة في الفارسية أو الإنكليزية
