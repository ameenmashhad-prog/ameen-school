## القرار المعماري
بناءً على اختيارك:
- **بنية جديدة كاملة**
- **البداية بمحرك الاستمارات**
- **قاموس مالي مقترح**

تم إنشاء طبقة مستقلة موازية داخل المشروع الحالي في:

## ملاحظة تشغيلية مهمة
هذا التنفيذ هو **scaffold معماري فعلي ومتعمق** داخل مجلد مستقل، ويحتاج لاحقًا:
1. تثبيت dependencies داخل `next-forms-v3`
2. توفير الخطوط المحلية داخل `public/fonts`
3. ربط RPCات الفعلية في Supabase
4. تحديد أول Form Production-ready وربطه فعليًا بقاعدة البيانات

## ما تم بعد ذلك
تمت إضافة نسخة Production-ready أولية من:
- **استمارة تسجيل الطالب**

وتشمل:
- أقسام فعلية داخل النموذج
- Draft محلي + Draft عبر RPC
- Submit RPC مستقل
- Validation أوضح
- Tracking ID بعد الإرسال
- بطاقة نجاح قابلة للطباعة
- معاينة جانبية ونسخة طباعة أولية
- تهيئة أولية لمسار signed upload عبر RPC تذكرة رفع
- صفحة نجاح مستقلة بعد الإرسال

## ما تم بعد ذلك أيضاً
تم تنفيذ طبقة رفع فعلية للمرفقات عبر الخادم، وتشمل:
- إصدار تذكرة رفع عبر RPC
- رفع الملف الثنائي إلى Supabase Storage عبر Route خادمي
- توثيق مسار `bucket/object_path` بعد الرفع
- تمرير مرجع المرفق المرفوع ضمن submit payload النهائي
- صفحة نجاح مستقلة بعد الإرسال

## الخطوة التالية المقترحة
بعد هذه النسخة الإنتاجية الأولية المتقدمة، أنسب مسار هو:
- تحسين طبقة التوقيع الإلكتروني النهائي
- أو الانتقال إلى استمارة إنتاجية ثانية مثل طلب الإجازة
- أو بناء لوحة استعراض submissions الخاصة بهذا المحرك

## ما تم بعد ذلك أيضاً
- تمت إضافة **استمارة طلب الإجازة** كنسخة Production-ready أولية على نفس المحرك، مع submit مستقل ورفع مرفقات اختياري وصفحة نجاح مستقلة.
