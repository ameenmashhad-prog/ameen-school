# قائمة UAT السريعة — Family Registration v3

## الهدف
التحقق أن النسخة العائلية الجديدة تحقق المطلوب العملي:
- إدخال بيانات الأسرة مرة واحدة
- عدم تكرار بيانات الأب والعائلة مع كل طالب
- إضافة أكثر من طالب بسهولة
- حفظ الطلب وإرساله وطباعته

---

## 1) فتح الصفحة
المسار:
- `/ar/forms/family-registration-v3`

### المتوقع
- [ ] الصفحة تفتح بدون خطأ
- [ ] يظهر عنوان: `تسجيل الأسرة والطلاب — نسخة عائلية حديثة`
- [ ] تظهر أقسام:
  - بيانات ولي الأمر
  - بيانات الأم
  - بطاقات الطلاب
  - السياق العائلي والصحي
  - الرسوم والأمور المالية
  - الوثائق والمرفقات
  - الاعتماد والطباعة

---

## 2) اختبار بيانات ولي الأمر
### أدخل القيم التالية
- اسم ولي الأمر
- اسم الأب لولي الأمر
- اسم العائلة
- الهاتف الأساسي
- تاريخ الميلاد

### المتوقع
- [ ] يتم قبول البيانات بدون أخطاء
- [ ] يتم توليد اسم مستخدم مقترح لولي الأمر
- [ ] لا تحتاج إعادة إدخال اسم العائلة في كل مكان

---

## 3) اختبار بيانات الأم
### أدخل القيم التالية
- اسم الأم
- اسم الأب للأم
- اسم العائلة للأم
- الهاتف

### المتوقع
- [ ] البيانات تُحفظ داخل نفس الطلب العائلي
- [ ] اسم العائلة للأم يمكن أن يتبع العائلة أو يُعدّل إذا لزم

---

## 4) اختبار بطاقة الطالب الأولى
### أدخل فقط
- اسم الطالب
- تاريخ الميلاد
- الجنس
- الصف

### المتوقع
- [ ] حقل `اسم الأب` يمتلئ تلقائيًا من بيانات ولي الأمر
- [ ] حقل `اسم العائلة` يمتلئ تلقائيًا من اسم العائلة
- [ ] `الاسم الكامل المحسوب` يتولد تلقائيًا
- [ ] اسم المستخدم المقترح للطالب يتولد تلقائيًا
- [ ] كلمة المرور الأولية تتولد من تاريخ الميلاد

### تحقق أساسي مهم
- [ ] لا تضطر لإعادة كتابة اسم الأب بالكامل من جديد
- [ ] لا تضطر لإعادة كتابة اسم العائلة من جديد

---

## 5) اختبار override داخل الطالب
### غيّر يدويًا
- اسم الأب داخل بطاقة الطالب
أو
- اسم العائلة داخل بطاقة الطالب

### المتوقع
- [ ] يتحول الحقل من inherited إلى manual override
- [ ] يتحدث الاسم الكامل المحسوب وفق القيمة الجديدة
- [ ] يمكن الضغط على `إعادة الربط مع بيانات الأسرة`
- [ ] يعود الطالب إلى الاسم الموروث من الأسرة عند إعادة الربط

---

## 6) اختبار إضافة طالب ثانٍ
### اضغط
- `إضافة طالب جديد`

### المتوقع
- [ ] تظهر بطاقة جديدة
- [ ] البطاقة الجديدة ترث اسم الأب والعائلة تلقائيًا
- [ ] لا يتم تكرار إدخال بيانات ولي الأمر مرة ثانية
- [ ] يمكن حذف الطالب الثاني دون كسر الطلب

---

## 7) اختبار منع التكرار
### أدخل نفس الاسم الكامل لطالبين

### المتوقع
- [ ] يظهر تنبيه بوجود تكرار في أسماء الطلاب داخل نفس الطلب
- [ ] يمنع الإرسال حتى تُصحح الأسماء

---

## 8) اختبار القسم المالي
### أدخل دفعتين
- دفعة مرتبطة بطالب محدد
- دفعة عامة للأسرة

### المتوقع
- [ ] جدول الدفعات يقبل الربط بطالب أو بالعائلة
- [ ] المجموع الكلي يتحدث بشكل صحيح
- [ ] القسم المالي يبقى عائليًا لا مكررًا لكل طالب

---

## 9) اختبار الوثائق والمرفقات
### جرّب
- إرفاق ملف عائلي/صحي
- تجهيز upload ticket

### المتوقع
- [ ] يتم تجهيز التذكرة بنجاح
- [ ] يظهر رقم التذكرة
- [ ] يظهر وضع المرفق بشكل واضح

---

## 10) اختبار الحفظ
### جرّب
- حفظ يدوي
- ترك الصفحة قليلًا للحفظ التلقائي

### المتوقع
- [ ] تظهر حالة حفظ واضحة
- [ ] لا تضيع البيانات بعد التحديث
- [ ] تبقى بطاقات الطلاب والدفعات كما هي

---

## 11) اختبار الإرسال
### اضغط
- `إرسال الطلب العائلي`

### المتوقع
- [ ] ينتقل إلى صفحة نجاح
- [ ] يظهر tracking/reference
- [ ] يظهر اسم مرجعي مناسب

---

## 12) اختبار لوحة الطلبات المرسلة
المسار:
- `/ar/forms/submissions`

### المتوقع
- [ ] يظهر الطلب الجديد بنوع `family-registration-v3`
- [ ] يظهر `guardian_name` بشكل صحيح
- [ ] يظهر `applicant_name` من أول طالب بشكل صحيح
- [ ] يمكن فتح التفاصيل
- [ ] تظهر `students[]` و `payment_entries[]` داخل payload
- [ ] يمكن تغيير الحالة إلى reviewed أو archived

---

## 13) اختبار الطباعة
### اضغط
- `طباعة المعاينة`

### المتوقع
- [ ] تظهر ورقة عائلية رئيسية
- [ ] يظهر ملحق مستقل لكل طالب
- [ ] تظهر بيانات ولي الأمر مرة واحدة في النسخة الرئيسية
- [ ] تظهر بيانات كل طالب في ملحقه بدون تكرار إدخال الأب يدويًا

---

## 14) معايير النجاح النهائي
يعتبر `family-registration-v3` ناجحًا إذا تحققت الشروط التالية:
- [ ] بيانات ولي الأمر تُكتب مرة واحدة فقط
- [ ] اسم الأب والعائلة يورَّثان تلقائيًا للطلاب
- [ ] الاسم الكامل للطالب يُحسب تلقائيًا
- [ ] يمكن إضافة أكثر من طالب بسهولة
- [ ] يمكن عمل override عند الحاجة
- [ ] يعمل الحفظ والإرسال
- [ ] تظهر البيانات في لوحة الطلبات
- [ ] تعمل الطباعة العائلية والملحقات
